# ทดสอบ: เล่าอาการสำคัญแล้ว AI กรอกช่องอื่นให้

กฎอยู่ใน `docs/knowledge.md` ข้อ 78 และโค้ดอยู่ใน `lib/er/er_flow_home/features/register/register_page.dart` (`_qCcRulePicks`, `_qGcsRules`, `_qLocRules`, `_qCcApply`, `_qCcAi`)

## วิธีทดสอบ

1. เปิดหน้าลงทะเบียน แล้วไปที่ขั้นคัดกรอง ส่วนอาการ ใช้ผู้ป่วยที่ช่องยังว่าง
2. ในการ์ดอาการสำคัญ แตะปุ่มคีย์บอร์ด แล้ววางคำเล่าของเคสลงในช่อง
3. กด "บันทึก" ในรอยเว้ามุมขวาล่าง
4. มุมขวาบนของช่องคำเล่าขึ้น "AI กำลังกรอก…" แล้วเปลี่ยนเป็น "AI กรอกให้ n ช่อง"
5. ช่องที่ถูกเติมเรืองแสงสี AI แวบหนึ่ง ตรวจค่าในแต่ละช่องตามตาราง

## เคส 1: หลายอาการ อุบัติเหตุ + ความดัน + GCS

คำเล่า:

```
โดนมีดแทงร้องจ๊าก เจ็บ 10 คะแนน ปวดหัวด้วย ท้องเสียด้วย พูดไม่ชัด ซับสน ซึม ทำร้ายเจ้าหน้าที่ โดนรถชนก่อนมาถึงขาหัก ตกตึกด้วย ความดัน 140/90 ไม่ลืมตา ทำตามคำสั่งไม่ได้ ไม่ส่งเสียงพูดไรเลย เปิด fast track ด่วนๆ
```

| ช่อง | ค่าที่ควรได้ | มาจากคำว่า |
|---|---|---|
| ประเภทผู้ป่วย | อุบัติเหตุ, ฉุกเฉิน | โดนมีดแทง, โดนรถชน, ตกตึก / แขนขาอ่อนแรง (อาการวิกฤต) |
| อาการ | แขนขาอ่อนแรง, อุบัติเหตุรุนแรง, ปวดท้อง, แผล/บาดเจ็บ, ปวดศีรษะ (ตามกฎคำ + AI) | พูดไม่ชัด, โดนรถชน, ท้องเสีย, โดนมีดแทง, ปวดหัว |
| ระดับความปวด | 10/10 | เจ็บ 10 คะแนน |
| ความดัน | 140/90 mmHg | ความดัน 140/90 |
| GCS การลืมตา (E) | E1 ไม่ลืมเลย | ไม่ลืมตา |
| GCS การพูด (V) | V1 ไม่ออกเสียงเลย | ไม่ส่งเสียงพูด |
| GCS การเคลื่อนไหว (M) | **ว่าง** (ต้องไม่ถูกเติม) | "ทำตามคำสั่งไม่ได้" บอกแค่ว่าไม่ใช่ M6 ยังไม่รู้ระดับ พยาบาลประเมินเอง |
| ความรู้สึกตัว | ซึม | ซึม (หนักกว่าสับสน) |

สิ่งที่ต้องไม่เกิด:

- ประเภทผู้ป่วยต้องไม่มี "ตรวจโรคทั่วไป"
- GCS M ต้องว่าง GCS รวมในหัวหน้าจอจึงยังคำนวณไม่ได้
- ชีพจร การหายใจ อุณหภูมิ ออกซิเจน และน้ำตาลต้องว่าง เพราะคำเล่าไม่ได้บอกตัวเลข
- "เปิด fast track ด่วนๆ" ไม่ได้เปิด fast track เอง ระบบแค่แนะนำ ให้พยาบาลกดเปิดเอง

## เพิ่มเคสใหม่

คัดลอกหัวข้อ "เคส" ด้านบน ใส่คำเล่าจริงที่เจอ แล้วเขียนค่าที่ควรได้ทีละช่อง รวมถึงช่องที่ต้องว่าง
